# The EchoedWords Initiative

You know how words get distorted and misinterpreted as they spread?

This is it.

Our goal is to make the world just a little bit weirder, one step at a time.

An ongoing effort to produce things that probably don't need to exist.

Some are useful, some are interesting, and some just make the world bleed.
