# AI Usage 

repos on this account may occasionally use AI-assisted tools. 
GitHub Copilot's commit message generation, for instance, is genuinely useful.

We do, however, strongly disapprove of AI-generated code. 
The point of making strange things is to explore ideas, understand them, and discover something along the way.
We are not interested in accumulating software for the sake of accumulating software. Nor do we believe that generating a thousand lines of code is inherently more impressive than writing ten.

You can ask a machine to make something weird. It will happily produce something that looks weird. But if all you've contributed is the request, what exactly have you created?
